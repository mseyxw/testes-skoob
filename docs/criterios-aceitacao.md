▶︎ **Critérios de aceitação**

<br>

**RF01: O sistema deve permitir buscar um livro pelo título.**

- Quando pesquisar o título de um livro, o sistema deve exibir esse livro nos resultados.
- Quando pesquisar caracteres aleatórios, o sistema deve informar que nenhum livro foi encontrado.

<br>

**RF02: O sistema deve permitir adicionar um livro a estante com um status específico (Lido, Lendo, Quero Ler, Relendo e Abandonei).**

- Quando escolher um status, o livro deve aparecer na aba desse status na estante.
- Quando trocar o status para "Abandonei", o livro deve sair da aba anterior e aparecer apenas na aba correspondente.

<br>

**RF03: O sistema deve permitir escrever e salvar uma resenha sobre um livro.**

- O sistema não deve permitir que resenhas vazias não sejam publicadas.
- O sistema deve permitir que resenhas com muitos caracteres sejam aceitas e publicadas.

<br>

**RF04: O sistema deve permitir marcar uma resenha com alerta de “Spoiler”.**

- Caso uma resenha seja marcada com “Contém spoilers” deve aparecer para os outros usuários com o texto tampado e com mensagem de alerta de spoiler.

<br>

**RF05: O sistema deve permitir atribuir uma nota de 1 a 5 estrelas a um livro da estante.**

- Quando um livro é avaliado, as estrelas selecionadas devem ficar preenchidas.
- Ao salvar uma nota de estrelas de um livro, essa informação deve ser salva e aparecer no perfil do usuário.

<br>

**RF06: O sistema deve manter os dados do perfil sincronizados entre a versão mobile e a web.**

- Caso a foto de perfil seja alterada em uma plataforma deve aparecer atualizada na outra.
