▶︎**Definição do Escopo**

**Aplicação:** Skoob, uma rede social voltada para leitores, na qual pode-se criar uma estante virtual para organizar os livros e interagir com outros usuários.

**Fluxo testado:** busca, avaliação e resenha de livros, ou seja, o caminho que os usuários (inclusive eu), utilizam todos os dias.

**Objetivo dos testes:** verificar se as principais funcionalidades que os usuários utilizam, funcionam da maneira que deveriam.

**O que faz parte do escopo:**

- Busca de livros
- Estante virtual
- Resenhas
- Sincronização dos dados do perfil entre versão mobile e web

**O que é fora do escopo:**

- Feed em que os usuários interagem
- Cadastro de novos livros e autores
- Metas de leitura
