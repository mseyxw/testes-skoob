▶︎ **Objetivo dos testes**

Verificar se as principais funcionalidades do Skoob utilizadas pelos usuários funcionam corretamente. Também verificar se os dados do perfil ficam sincronizados entre o aplicativo mobile e a versão web.

<br>

▶︎ **Funcionalidades que foram testadas:**

Busca de livros <br>
Estante virtual <br>
Resenhas <br>
Sincronização Web/App <br>

<br>

▶︎ **Funcionalidades que não foram testadas:**

Feed em que os usuários interagem <br>
Cadastro de novos livros e autores <br>
Metas de leitura <br>

<br>

▶︎ **Ambiente Utilizado:**

Os testes foram realizados na minha conta particular do Skoob, usando o aplicativo mobile e a versão web.

<br>

▶︎ **Navegador, dispositivo ou sistema operacional:**

Celular: Iphone 15 pro com versão do iOS 26.6.2 <br>
Aplicativo: Skoob para iOS na versão 5.6.5 <br>
Computador: Windows utilizando o navegador Edge na versão 157.0.4341.46 <br>

<br>

▶︎ **Tipos de testes que foram executados:** <br>

Testes funcionais que verificam se cada funcionalidade faz o que deveria. <br>
Testes negativos que verificam se o sistema se comporta bem com entradas inválidas e com valores extremos. <br>
Teste de sincronização que verifica se uma alteração feita no app aparece na web.<br>

<br>

▶︎ **Critérios utilizados para considerar os testes concluídos:**
Todos os casos de teste planejados foram executados.
Cada caso recebeu o status PASS ou FAIL, com um print como evidência de sucesso ou falha.
Todo requisito tem pelo menos um caso de teste.
