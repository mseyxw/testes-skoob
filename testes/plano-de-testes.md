**Objetivo dos testes**

Verificar se as principais funcionalidades do Skoob utilizadas pelos usuários funcionam corretamente. Também verificar se os dados do perfil ficam sincronizados entre o aplicativo mobile e a versão web.



**Funcionalidades que foram testadas:**

Busca de livros
Estante virtual
Resenhas
Sincronização Web/App



**Funcionalidades que não foram testadas:**

Feed em que os usuários interagem
Cadastro de novos livros e autores
Metas de leitura



**Ambiente Utilizado:**

Os testes foram realizados na minha conta particular do Skoob, usando o aplicativo mobile e a versão web.



**Navegador, dispositivo ou sistema operacional:**

Celular: Iphone 15 pro com versão do iOS 26.6.2
Aplicativo: Skoob para iOS na versão 5.6.5
Computador: Windows utilizando o navegador Edge na versão 157.0.4341.46



**Tipos de testes que foram executados:**

Testes funcionais que verificam se cada funcionalidade faz o que deveria.
Testes negativos que verificam se o sistema se comporta bem com entradas inválidas e com valores extremos.
Teste de sincronização que verifica se uma alteração feita no app aparece na web.


**Critérios utilizados para considerar os testes concluídos:**
Todos os casos de teste planejados foram executados.
Cada caso recebeu o status PASS ou FAIL, com um print como evidência de sucesso ou falha.
Todo requisito tem pelo menos um caso de teste.
