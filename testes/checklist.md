**Checklist de testes**

1.(☑) Usuário consegue procuarar no campo de busca <br>
2.(☑) Usuário consegue realizar uma através da pesquisa do título do livro <br>
3.(☑) Caso o usuário realize uma inválida, é exibida mensagem de nenhum resultado encontrado <br>
4.(☑) O livro é adicionado a estante do usuário com o status escolhido <br>
5.(☑) Quando é realizada a troca do status, o livro muda para a aba correta <br>
6.(☑) Quando é feita uma valiação em estrelas é registrada corretamente <br>
7.(☑) Quando o usuário vai fazer uma resenha, o campo de escrever informa o mínimo de caracteres para realizar a postagem <br>
8.(☑) Quando o usuário vai fazer uma resenha, essa resenha vazia não pode ser publicada <br>
9.(☑) Resenha com muitos caracteres é aceita <br>
10.(☑) Caso uma resenha seja marcada com spoiler, na publicação ela aparece tampada e com alerta	<br>
11.(☒) Foto de perfil alterada no app mobile aparece na versão web <br>
